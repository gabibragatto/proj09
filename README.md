# Projeto — Estruturas de Repetição com `do-while`
## Descrição
Este projeto contém 5 exercícios desenvolvidos em JavaScript utilizando a estrutura de repetição `do-while`.
Os programas foram criados para praticar:
- Estruturas de repetição;
- Validação de dados;
- Menus interativos;
- Condições;
- Entrada e saída de dados com `prompt` e `alert`.

# Exercícios Desenvolvidos
## 1 - Validação de Senha
O programa solicita uma senha ao usuário até que a senha correta seja digitada.
### Funcionalidades:
- Senha fixa no sistema;
- Repetição até acertar;
- Mensagem de acesso permitido.
---
## 2 - Soma com Confirmação
O usuário digita números inteiros e o sistema soma os valores até que ele decida parar.
### Funcionalidades:
- Soma acumulativa;
- Confirmação para continuar;
- Exibição do resultado final.
---
## 3 - Jogo de Adivinhação
O sistema possui um número secreto entre 1 e 10. O usuário deve tentar acertar.
### Funcionalidades:
- Número secreto;
- Contador de tentativas;
- Mensagem de parabéns ao acertar.
---
## 4 - Validação de Cadastro
O programa solicita o nome de um produto e valida se ele possui no mínimo 3 caracteres.
### Funcionalidades:
- Validação de entrada;
- Mensagem de erro;
- Cadastro confirmado.
---
## 5 - Sistema de Cafeteria
Menu interativo de cafeteria onde o usuário pode adicionar itens ao pedido.
### Funcionalidades:
- Menu com opções;
- Soma automática do pedido;
- Tratamento de opção inválida;
- Finalização do pedido.
